# Vault Peek 42 — Minecraft 1.21.4 Fabric

Клиентский прототип мода, который открывает справочное окно по клавише **P**. В окне можно ввести сид мира и увидеть возможную добычу из зловещего хранилища с настоящими иконками предметов Minecraft.

## Что уже есть

- Minecraft Java Edition **1.21.4** + Fabric.
- Окно по клавише **P**.
- Поле ввода сида мира.
- Карточки предметов с игровыми иконками и краткими подписями.
- GitHub Actions автоматически собирает JAR при изменениях в репозитории.

## Важно про предсказание

**Точная генерация наград по сиду пока не реализована.** Сейчас список предметов справочный: он не меняется в зависимости от введённого сида и не является обещанием конкретной добычи. Для настоящего предсказания нужно восстановить алгоритм выбора наград в Minecraft 1.21.4 и определить состояние/позицию последовательности для нужного хранилища. На сервере одного сида может быть недостаточно.

## Как получить JAR без установки Gradle на компьютере

1. Открой вкладку **Actions** этого репозитория.
2. Выбери workflow **Build Vault Peek 42**.
3. Открой последний успешный запуск.
4. Внизу страницы скачай artifact **VaultPeek42-jar**.
5. Распакуй скачанный ZIP и положи JAR в папку `.minecraft/mods`.
6. Установи Fabric Loader для Minecraft 1.21.4 и подходящую версию Fabric API.
7. Запусти игру и нажми **P**.

Если сборка завершилась ошибкой, открой вкладку Actions, выбери неудачный запуск и сохрани текст ошибки из лога.

## Ручная сборка

Нужна Java JDK 21 и Gradle 8.10.2 или совместимый. В корневой папке проекта выполни:

```bash
gradle build
```

Готовый файл будет в `build/libs/`.
