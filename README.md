# Vault Peek 42 — Minecraft 1.21.4 Fabric

Клиентский мод с окном по клавише **P**. Он рассчитывает последовательность добычи зловещих хранилищ для введённого числового сида и показывает её с игровыми иконками.

## Что есть в текущем прототипе

- Minecraft Java Edition **1.21.4** + Fabric.
- Окно по клавише **P**.
- Ввод сида мира и начальной позиции.
- **Показать 12** — отобразить следующие 12 предсказанных открытий.
- **Следующие** — перейти к следующему набору из 12.
- Нативный генератор добычи на основе [Cubiomes](https://github.com/xpple/cubiomes).

Некоторые особые и оружейные предметы отображаются обобщённой иконкой с вопросительным знаком, а не конкретным названием.

## Важно про номер последовательности

Номер — позиция в последовательности наград, начинающейся с введённой позиции. Для нового одиночного мира начните с **0**.

На многопользовательском сервере другие игроки могли уже открыть хранилища. Тогда последовательность могла продвинуться: одного сида недостаточно, если текущая позиция неизвестна. Нужно знать или отдельно восстановить смещение (*offset*). Автоматическое восстановление смещения по ранее увиденным наградам пока не реализовано.

Это первая реализация алгоритма. Перед тем как полагаться на результат, сравните несколько предсказаний с фактически открытыми хранилищами в Minecraft 1.21.4.

## Скачать JAR

1. Открой вкладку [Actions](https://github.com/lokibogach-boop/VaultPeek42/actions).
2. Выбери последний **успешный** запуск workflow **Build Vault Peek 42**.
3. Скачай artifact **VaultPeek42-windows-x86_64**.
4. Распакуй ZIP и положи JAR в папку `.minecraft/mods`.
5. Установи Fabric Loader для Minecraft 1.21.4 и Fabric API версии для 1.21.4.
6. Запусти игру и нажми **P**.

Если последний запуск упал, скачивать его artifact нельзя — открой лог и проверь более свежий успешный запуск.
