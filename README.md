# Vault Peek 42 — Minecraft 1.21.4 Fabric

Клиентский мод с окном по клавише **P**. Он рассчитывает последовательность наград зловещих хранилищ для введённого числового сида и показывает их настоящими игровыми иконками.

## Что есть в текущем прототипе

- Minecraft Java Edition **1.21.4** + Fabric.
- Окно по клавише **P**.
- Ввод сида мира и начальной позиции в последовательности.
- **Показать 12** — отобразить следующие 12 предсказанных открытий.
- **Следующие** — перейти к следующему набору из 12.
- **Найти ядро** — просмотреть следующие 5 000 позиций и показать первое найденное тяжёлое ядро, если оно есть в этом диапазоне.
- Нативный генератор добычи на основе [Cubiomes](https://github.com/xpple/cubiomes), закреплённый на конкретном коммите.

## Важно: как читать номер

Номер — позиция в последовательности наград, начинающейся с введённой позиции. Для нового одиночного мира обычно начинайте с **0**.

На многопользовательском сервере другие игроки могли уже открыть хранилища. Тогда последовательность могла продвинуться: один сид без текущего смещения не сообщает, какая именно позиция будет следующей. В таком случае нужно знать или отдельно восстановить текущее смещение. Автоматическое восстановление смещения по ранее выпавшим предметам ещё не реализовано.

Перед тем как полагаться на результат в своём мире, сравните несколько предсказаний с фактически открытыми хранилищами. Это первая реализация алгоритма и она требует проверки на Minecraft 1.21.4.

## Скачать JAR

1. Открой вкладку [Actions](https://github.com/lokibogach-boop/VaultPeek42/actions).
2. Выбери последний **успешный** запуск workflow **Build Vault Peek 42**.
3. Внизу страницы скачай artifact **VaultPeek42-windows-x86_64**.
4. Распакуй ZIP и положи JAR в папку `.minecraft/mods`.
5. Установи Fabric Loader для Minecraft 1.21.4 и Fabric API версии для 1.21.4.
6. Запусти игру и нажми **P**.

Если последний запуск упал, скачивать его артефакт нельзя — открой лог и дождись следующей успешной сборки.

## Ручная сборка

Нужны Java JDK 21, Gradle 8.11.1, CMake, Ninja и UCRT64 toolchain из MSYS2. Нужно также клонировать репозиторий вместе с подмодулем Cubiomes.
